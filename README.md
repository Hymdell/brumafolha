# Brumafolha — Crônicas de um Reino

Jogo incremental medieval em TypeScript. Você começa sozinho numa clareira, reúne recursos, acende uma fogueira, acolhe moradores e transforma trabalho manual numa aldeia automatizada.

## Executar

```sh
npm install
npm run dev
```

O salvamento fica no navegador (`localStorage`), com progresso offline limitado a oito horas. Use os botões no canto superior para exportar, importar ou reiniciar uma partida.

## Sistemas desta versão

- Coleta manual, receitas e recursos com limite de estoque.
- Mapa ilustrado que recebe as construções concluídas; clique numa construção para inspecioná-la.
- Fila de construção, moradia, população, recrutamento pago com provisões e atribuição de ofícios.
- Produção e consumo por segundo, horta, lenhadores, oficina e conversão de madeira em tábuas e ferramentas.
- Pesquisas com pré-requisitos, custo e duração; exploração e primeiros indícios de magia.
- Salvamento automático, progresso offline, importação, exportação e reinício confirmado.

O conteúdo atual cobre o começo solitário até a fundação de uma aldeia e inclui pontos de expansão para exploração regional e arcana.
